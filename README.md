## Overview

This repository contains a basic **local area network (LAN)** built in **Cisco Packet Tracer**. The provided topology screenshot shows a **star topology** with four end devices connected to a central **Cisco 2960-24TT switch**. The original simulation file is available for inspection in Packet Tracer.

## How to explore the project

1. Install **Cisco Packet Tracer**.
2. Download [`Nihal_Hameed_Assignment1.pkt`](Nihal_Hameed_Assignment1.pkt).
3. Launch Packet Tracer and choose **File → Open**.
4. Select the downloaded file to inspect its network topology and saved settings.
5. Use Packet Tracer's simulation and device tools to check the configuration and connectivity.
